# What's My Time Worth?

Interactive Time Worth Evaluator — calculate your real-time financial value down to the second, track earnings during breaks and meetings, convert purchases into work hours, and share summary cards.

## Quick start

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start local development server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |

## Features

- Income setup with monthly / annual / hourly rates and multi-currency support
- Live earnings ticker with break & meeting presets
- Hours-to-buy purchase opportunity cost calculator
- Outsource vs DIY decision tool
- Downloadable / shareable PNG summary cards
- Dark / light theme with localStorage persistence (no backend)

## Stack

React · Vite · Tailwind CSS · html2canvas
